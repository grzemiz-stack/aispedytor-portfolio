## Pushing

Always push this repository with:

```
ALLOW_PUSH=1 git push && git status -sb | head -1
```

There is no hook here (`ALLOW_PUSH` changes nothing in this repository; the
form matches the original repository, where a `pre-push` hook needs it).
The second part shows at once whether the branch is still `[ahead]`: on
8 October one push did not reach GitHub, and a failed push leaves no trace
in the repository.

## Open after the October 2026 checking review

What the checking review found and this version does **not** fix — each in
[known-issues](docs/known-issues.md) with the details (API paths under
`apps/api/src/`):

- Offers from e-mail and import have no contractor until someone sets it, so the blacklist and contractor risk do not see them (`email-agent/`, `offers/offers.service.ts` `importOffers`).
- The blacklist guards against mistakes, not intent: a dispatcher can add the same offer again without a contractor; an ADMIN's acceptance, blacklist change or detach is only a log line (`offers/offers.service.ts`, `contractors/contractors.service.ts`).
- Negotiation estimates a missing distance as a straight line × 1.3 and shows a margin the saved offer does not have (`negotiation/negotiation.service.ts`).
- Demands ignore the dead-offer rule in search, counts and `DEMAND_MATCH` notifications (`demands/demands.service.ts`).
- A new city or country through `PATCH /offers/:id` keeps the old saved route in the margin, negotiation and LTL until the route is calculated again (`offers/offers.service.ts` `update`).
- `offers:recompute-economics` for a company without a cost per km empties the economics of every offer, accepted ones too (`offers/recompute-economics.ts`).
- The "≤ X %" hint says "calculate the route", which saves nothing without a toll provider (`apps/web/src/lib/margin.ts`, `route-planner/route-planner.service.ts`).
- The offer list shows "€/km" for every currency (`apps/web/src/app/(dashboard)/offers/page.tsx`).
- Km per country: each border is about ±3 km off, and a country lying between two probes of the same country is not seen (`route-planner/osrm-calculator.service.ts` `detectCountries`).
- The first calculation of a long route takes up to about 80 s (Nominatim, 1 request per second) — the proxy timeout must be at least 120 s (`docs/DEPLOYMENT.md`).
- A hub-table estimate saved before this version cannot be told from a real route (`common/route-trust.ts`).
- Some days and months are counted in the server's time zone — set `TZ` (`docs/DEPLOYMENT.md`; `vehicles/vehicles.service.ts`, `analytics/`).
- The web app has no script Content Security Policy and keeps tokens in `localStorage` (`apps/web/next.config.js`, `apps/web/src/lib/api-client.ts`).
- No toll provider is registered: toll comes only from a manual entry (`tolls/tolls.module.ts`).
